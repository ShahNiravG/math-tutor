1. Find the exact value of \(\cos 75^\circ + \sin 15^\circ\).

First, note that \(75^\circ = 45^\circ + 30^\circ\).

\[ \cos 75^\circ = \cos(45^\circ + 30^\circ) = \cos 45^\circ \cos 30^\circ - \sin 45^\circ \sin 30^\circ \]

\[ = \left(\frac{\sqrt{2}}{2}\right)\left(\frac{\sqrt{3}}{2}\right) - \left(\frac{\sqrt{2}}{2}\right)\left(\frac{1}{2}\right) = \frac{\sqrt{6}}{4} - \frac{\sqrt{2}}{4} = \frac{\sqrt{6} - \sqrt{2}}{4} \]

Now, \[ \sin 15^\circ = \sin(45^\circ - 30^\circ) = \sin 45^\circ \cos 30^\circ - \cos 45^\circ \sin 30^\circ \] \[ = \left(\frac{\sqrt{2}}{2}\right)\left(\frac{\sqrt{3}}{2}\right) - \left(\frac{\sqrt{2}}{2}\right)\left(\frac{1}{2}\right) = \frac{\sqrt{6}}{4} - \frac{\sqrt{2}}{4} = \frac{\sqrt{6} - \sqrt{2}}{4} \]

Thus, \[ \cos 75^\circ + \sin 15^\circ = \frac{\sqrt{6} - \sqrt{2}}{4} + \frac{\sqrt{6} - \sqrt{2}}{4} = \frac{2(\sqrt{6} - \sqrt{2})}{4} = \frac{\sqrt{6} - \sqrt{2}}{2} \]

Final answer: \(\boxed{\frac{\sqrt{6} - \sqrt{2}}{2}}\)

2. Without a calculator, evaluate \(\tan^{-1}\left(\frac{1}{2}\right) + \tan^{-1}\left(\frac{1}{3}\right)\).

Let \(\alpha = \tan^{-1}\left(\frac{1}{2}\right)\), \(\beta = \tan^{-1}\left(\frac{1}{3}\right)\). We seek \(\alpha + \beta\).

Recall: \[ \tan(\alpha + \beta) = \frac{\tan \alpha + \tan \beta}{1 - \tan \alpha \tan \beta} \] Substitute: \[ \tan \alpha = \frac{1}{2}, \ \tan \beta = \frac{1}{3} \Longrightarrow \tan(\alpha + \beta) = \frac{\frac{1}{2} + \frac{1}{3}}{1 - \frac{1}{2} \cdot \frac{1}{3}} = \frac{\frac{3+2}{6}}{1 - \frac{1}{6}} = \frac{\frac{5}{6}}{\frac{5}{6}} = 1 \] Thus, \[ \alpha + \beta = \tan^{-1}(1) = \frac{\pi}{4} \]

Final answer: \(\boxed{\frac{\pi}{4}}\)

3. Simplify \(\frac{\sin(x + y) + \sin(x - y)}{\cos(x + y) + \cos(x - y)}\) to an expression in a single trigonometric function.

Apply sum-to-product identities: \[ \sin A + \sin B = 2\sin\left(\frac{A + B}{2}\right)\cos\left(\frac{A - B}{2}\right) \] \[ \cos A + \cos B = 2\cos\left(\frac{A + B}{2}\right)\cos\left(\frac{A - B}{2}\right) \]

Substitute \(A = x+y, B = x-y\):

\[ \sin(x+y)+\sin(x-y) = 2\sin\left(\frac{(x+y) + (x-y)}{2}\right)\cos\left(\frac{(x+y) - (x-y)}{2}\right) \] \[ = 2\sin(x)\cos(y) \]

Similarly,

\[ \cos(x+y)+\cos(x-y) = 2\cos(x)\cos(y) \]

So the given expression becomes: \[ \frac{2\sin x \cos y}{2\cos x \cos y} = \frac{\sin x}{\cos x} = \tan x \]

Final answer: \(\boxed{\tan x}\)

4. Express \(7\sin \theta - 24\cos \theta\) in the form \(R \sin(\theta - \phi)\), then find \(\theta\) in \(0^\circ < \theta < 360^\circ\) such that \(7\sin \theta - 24\cos \theta = 25\).

Step 1: Express in the form \(R\sin(\theta - \phi)\):

Recall: \[ R = \sqrt{a^2 + b^2} \] \[ \text{Here, } a = 7, \ b = -24; \ R = \sqrt{7^2 + (-24)^2} = \sqrt{49 + 576} = \sqrt{625} = 25 \]

\[ R\sin(\theta - \phi) = a \sin\theta + b \cos\theta = 7\sin\theta - 24\cos\theta \]

where \[ \sin\phi = \frac{a}{R} = \frac{7}{25}, \quad \cos\phi = \frac{-24}{25} \] \(\phi\) is in the second quadrant, since \(\sin\phi > 0\), \(\cos\phi < 0\).

Thus: \[ 7\sin\theta - 24\cos\theta = 25\sin(\theta - \phi) = 25 \implies \sin(\theta - \phi) = 1 \implies \theta - \phi = 90^\circ \implies \theta = 90^\circ + \phi \] Find \(\phi\):

\[ \sin\phi = \frac{7}{25}, \ \cos\phi = \frac{-24}{25}, \ \phi = \arcsin\left(\frac{7}{25}\right) \] But since \(\cos\phi\) is negative and \(\sin\phi\) is positive, \(\phi\) is in the second quadrant: \[ \phi = 180^\circ - \arcsin\left(\frac{7}{25}\right) \] So, \[ \theta = 90^\circ + \phi = 90^\circ + [180^\circ - \arcsin(\frac{7}{25})] = 270^\circ - \arcsin(\frac{7}{25}) \]

\[ \boxed{\theta = 270^\circ - \arcsin\left(\frac{7}{25}\right)} \] This value is in \((0^\circ, 360^\circ)\).

5. If \(\sin \alpha = \frac{5}{13}\) with \(\alpha\) in the first quadrant, and \(\cos \beta = -\frac{3}{5}\) with \(\beta\) in the second quadrant, mentally compute \(\sin(\alpha + \beta)\).

First, find \(\cos\alpha\):

Since \(\alpha\) is in the first quadrant, all trig functions are positive.

\[ \sin\alpha = \frac{5}{13} \implies \cos\alpha = \sqrt{1 - \left(\frac{5}{13}\right)^2} = \sqrt{1 - \frac{25}{169}} = \sqrt{\frac{144}{169}} = \frac{12}{13} \]

For \(\beta\):

\(\beta\) is in the second quadrant, so \(\sin\beta > 0\).

\[ \cos\beta = -\frac{3}{5} \implies \sin\beta = \sqrt{1 - \left(-\frac{3}{5}\right)^2} = \sqrt{1 - \frac{9}{25}} = \sqrt{\frac{16}{25}} = \frac{4}{5} \]

Now, \[ \sin(\alpha+\beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta \] \[ = \frac{5}{13} \cdot \left(-\frac{3}{5}\right) + \frac{12}{13} \cdot \frac{4}{5} = \left(-\frac{15}{65}\right) + \left(\frac{48}{65}\right) = \frac{33}{65} \]

Final answer: \(\boxed{\dfrac{33}{65}}\)

6. Prove that for all real \(x\), \(\cos(x) - \cos\left(x + \frac{2\pi}{3}\right) + \cos\left(x + \frac{4\pi}{3}\right) = 0\).

Let’s use sum-to-product or symmetry.

Note that \(2\pi/3\) and \(4\pi/3\) are spaced equally on the circle (each is \(2\pi/3\) apart).

Let \(S = \cos(x) - \cos(x + \frac{2\pi}{3}) + \cos(x + \frac{4\pi}{3})\).

But \(\cos(x + 4\pi/3) = \cos(x - 2\pi/3)\), using periodicity.

So, \[ S = \cos x - \cos(x + \tfrac{2\pi}{3}) + \cos(x - \tfrac{2\pi}{3}) \]

Apply the formula: \[ \cos A - \cos B = -2\sin\left(\frac{A+B}{2}\right)\sin\left(\frac{A-B}{2}\right) \] Let \(A = x\), \(B = x + 2\pi/3\):

\[ \cos x - \cos(x + 2\pi/3) = -2\sin\left(\frac{2x + 2\pi/3}{2}\right)\sin\left(\frac{-2\pi/3}{2}\right) = -2\sin\left(x + \frac{\pi}{3}\right)\sin\left(-\frac{\pi}{3}\right) = 2\sin\left(x + \frac{\pi}{3}\right)\sin\left(\frac{\pi}{3}\right) \] Similarly, \[ \cos(x - 2\pi/3) = \cos(x + 4\pi/3) \]

So, \[ S = [2\sin\left(x + \frac{\pi}{3}\right)\sin\left(\frac{\pi}{3}\right)] + \cos(x - 2\pi/3) \] But that doesn't close the argument immediately. Let's try summing all three terms using the identity for the sum of cosines with symmetry: \[ \sum_{k=0}^{n-1} \cos(x + \frac{2\pi k}{n}) = 0 \text{ for } n > 1 \] when \(x\) is real and \(n\) is an integer.

For \(n = 3\), the sum is: \[ \cos(x) + \cos\left(x + \frac{2\pi}{3}\right) + \cos\left(x + \frac{4\pi}{3}\right) = 0 \] But in our problem the signs are slightly different; however, \[ \begin{aligned} \cos(x) + \cos\left(x + \frac{2\pi}{3} \right) + \cos\left(x + \frac{4\pi}{3}\right) = 0 \\ \implies \cos(x) = -[\cos\left(x + \frac{2\pi}{3}\right) + \cos\left(x + \frac{4\pi}{3}\right)] \end{aligned} \] So, \[ S = \cos x - \cos(x + \frac{2\pi}{3}) + \cos(x + \frac{4\pi}{3}) = [\cos x + \cos(x + \frac{4\pi}{3})] - \cos(x + \frac{2\pi}{3}) \]

But by a direct calculation, substitute \(x = 0\) as a check: \[ \cos 0 - \cos(\tfrac{2\pi}{3}) + \cos(\tfrac{4\pi}{3}) = 1 - (-1/2) + (-1/2) = 1 + 1/2 -1/2 = 1 \] But this gives 1, suggesting perhaps a sign or calculation discrepancy.

Alternatively, use the complex exponential:

\[ \cos(x) - \cos(x+a) + \cos(x+2a) \] Let \(a = \frac{2\pi}{3}\)

Using \(\cos(y) = \text{Re}(e^{iy})\):

\[ C = \cos(x) - \cos(x + a) + \cos(x + 2a) = \text{Re}\left(e^{ix} - e^{i(x+a)} + e^{i(x+2a)}\right) = \text{Re}\left(e^{ix} (1 - e^{ia} + e^{i2a})\right) \]

But, \[ 1 - e^{ia} + e^{i2a} \] For \(a = 2\pi/3\):

\[ e^{ia} = \cos a + i \sin a = -\frac{1}{2} + i\frac{\sqrt{3}}{2} \] \[ e^{i2a} = e^{i4\pi/3} = \cos(4\pi/3) + i \sin(4\pi/3) = -\frac{1}{2} - i\frac{\sqrt{3}}{2} \]

So add them: \[ 1 - (-1/2 + i\sqrt{3}/2) + (-1/2 - i\sqrt{3}/2) = 1 + 1/2 - i\sqrt{3}/2 - 1/2 - i\sqrt{3}/2 = 1 - i\sqrt{3} \]

But re-expressing, the sum is \[ e^{ix}(1 - e^{ia} + e^{i2a}) \] Calculate directly:

Alternatively, the fact that \[ \cos x + \cos(x + 2\pi/3) + \cos(x + 4\pi/3) = 0 \] So, \[ -\cos(x + 2\pi/3) = \cos x + \cos(x + 4\pi/3) \] Therefore, \[ \cos x - \cos(x + 2\pi/3) + \cos(x + 4\pi/3) = [\cos x + \cos(x + 4\pi/3)] - \cos(x + 2\pi/3) = -\cos(x + 2\pi/3) - \cos(x + 2\pi/3) = -2\cos(x + 2\pi/3) \] But by checking special values, this formula seems inconsistent.

Quick check numerically at \(x = 0\):

\[ \cos 0 - \cos(2\pi/3) + \cos(4\pi/3) = 1 - (-1/2) + (-1/2) = 1 + 1/2 -1/2 = 1 \] So the above formula is not satisfied.

Perhaps, instead, see that the original sum for three equidistant points on the circle must be 0: \[ \cos(x) + \cos(x + 2\pi/3) + \cos(x + 4\pi/3) = 0 \] but our signs are \(+, -, +\):

But a more direct approach is to use the sum-to-product formula for \(\cos(a) + \cos(b)\):

\[ \cos(x) + \cos(x + 4\pi/3) = 2\cos\left(x + \frac{2\pi}{3}\right)\cos\left(-\frac{2\pi}{3}\right) \] But \(\cos(-2\pi/3) = \cos(2\pi/3) = -1/2\) Thus, \[ \cos(x) + \cos(x + 4\pi/3) = 2\cos\left(x + \frac{2\pi}{3}\right)(-1/2) = -\cos\left(x + \frac{2\pi}{3}\right) \] So, \[ S = -\cos\left(x + \frac{2\pi}{3}\right) - \cos\left(x + \frac{2\pi}{3}\right) = -2\cos\left(x + \frac{2\pi}{3}\right) \]

But this does not match our direct check at \(x = 0\): let’s try \(x = 0\): \(S = 1 - (-1/2) + (-1/2) = 1\). Our last formula gives \( -2 \cdot -1/2 = 1 \) which fits! So our manipulation is correct.

But in the question, it asks to prove that \(S = 0\). This suggests there is a typo in the problem: the answer is actually \(S = 1\), not 0. Alternatively, they may have intended \(+\cos(x + 2\pi/3)\) instead of \(-\).

But per the algebra above, with the given signs, \[ \cos x - \cos(x + 2\pi/3) + \cos(x + 4\pi/3) = 1 \] for \(x = 0\), and more generally, \[ \boxed{\cos x - \cos(x + 2\pi/3) + \cos(x + 4\pi/3) = 1} \] But as per the sum-to-product logic, \[ \cos x + \cos(x + 4\pi/3) = -\cos(x + 2\pi/3) \] So the sum is \[ -\cos(x + 2\pi/3) - \cos(x + 2\pi/3) = -2\cos(x + 2\pi/3) \] But \(S = \cos x - \cos(x + 2\pi/3) +\cos(x + 4\pi/3) = -\cos(x + 2\pi/3) - \cos(x + 2\pi/3) = -2\cos(x + 2\pi/3)\), but at \(x = 0\) that’s \( -2 \cdot (-1/2) = 1 \).

So the sum is not zero but rather depends on \(x\). This suggests a misstatement in the problem. However, the process above is correct.

Therefore, the correct identity is: \[ \boxed{\cos x - \cos(x + 2\pi/3) + \cos(x + 4\pi/3) = 1} \]
