Study Guide: Chp 7.1 – Trigonometric Identities

1. Short Summary

This document introduces trigonometric identities, which are equations involving trigonometric functions that hold for all values in their domain. It covers the fundamental identities and properties (quotient, product, reciprocal, Pythagorean), and explains strategies for simplifying and proving trigonometric identities. Several examples and types of identities (even-odd, cofunction) are shown, along with guidance on algebraic manipulation and substitution.

2. Core Definitions, Theorems, and Formulas

Definitions

  • Identity: An equation that is true for all values of the variable(s).
  • Trigonometric Identity: An identity involving trigonometric functions.

Essential Properties and Identities

Quotient Properties:

  • \(\tan(x) = \frac{\sin(x)}{\cos(x)}\)
  • \(\cot(x) = \frac{\cos(x)}{\sin(x)}\)

Product Properties:

  • \(\tan(x)\cos(x) = \sin(x)\)
  • \(\tan(x)\cot(x) = 1\)

Reciprocal Properties:

  • \(\sin(x) = \frac{1}{\csc(x)}\)
  • \(\cos(x) = \frac{1}{\sec(x)}\)
  • \(\tan(x) = \frac{1}{\cot(x)}\)
  • \(\csc(x) = \frac{1}{\sin(x)}\)
  • \(\sec(x) = \frac{1}{\cos(x)}\)
  • \(\cot(x) = \frac{1}{\tan(x)}\)

Pythagorean Identities:

  • \(\sin^2(x) + \cos^2(x) = 1\)
  • \(1 + \tan^2(x) = \sec^2(x)\)
  • \(1 + \cot^2(x) = \csc^2(x)\)

Cofunction Identities:

  • \(\sin\left(\frac{\pi}{2} - x\right) = \cos(x)\)
  • \(\cos\left(\frac{\pi}{2} - x\right) = \sin(x)\)
  • \(\tan\left(\frac{\pi}{2} - x\right) = \cot(x)\)
  • \(\cot\left(\frac{\pi}{2} - x\right) = \tan(x)\)
  • \(\sec\left(\frac{\pi}{2} - x\right) = \csc(x)\)
  • \(\csc\left(\frac{\pi}{2} - x\right) = \sec(x)\)

Even-Odd Identities: (Not all listed, but examples would include)

  • \(\sin(-x) = -\sin(x)\) (odd)
  • \(\cos(-x) = \cos(x)\) (even)
  • \(\tan(-x) = -\tan(x)\) (odd)

3. Step-by-Step Study Guide

A. Understanding the Identities

1. Quotient, Product, and Reciprocal Properties

  • Know how to rewrite tan, cot, sec, csc, etc., in terms of sin and cos or as reciprocals.
  • Example: \(\tan(x) = \frac{\sin(x)}{\cos(x)}\), \(\cot(x) = \frac{\cos(x)}{\sin(x)}\).

2. Using Pythagorean Identities

  • Start with \(\sin^2(x) + \cos^2(x) = 1\).
  • Rearrangement gives two more forms:
  • \(\sin^2(x) = 1 - \cos^2(x)\)
  • \(\cos^2(x) = 1 - \sin^2(x)\)
  • Divide the basic identity by \(\cos^2(x)\) or \(\sin^2(x)\) to derive the others.

3. Cofunction and Even-Odd Identities

  • Cofunction identities relate the value of a function at angle \(x\) to its “partner” at \(\frac{\pi}{2} - x\).
  • Even-odd identities reflect symmetry properties (e.g., sine and tangent are odd, cosine is even).

B. Simplifying Trigonometric Expressions

  • Step 1: Change all functions to sines and cosines, if possible.
  • Step 2: Apply fundamental identities to simplify.
  • Step 3: Factor if there is a common factor.
  • Step 4: Combine terms using algebraic methods (common denominators, etc.).

Example: Simplify \(\sin(\theta) \sec(\theta)\): 1. \(\sec(\theta) = \frac{1}{\cos(\theta)}\) 2. \(\sin(\theta) \sec(\theta) = \frac{\sin(\theta)}{\cos(\theta)} = \tan(\theta)\)

C. Proving Identities

  • Work from one side of the equation to the other.
  • If stuck, convert everything to sines and cosines.
  • Use known identities and algebraic manipulation.
  • If both sides can be separately reduced to the same expression, the identity is verified.

D. Trigonometric Substitution

  • Substitute a trigonometric function for a variable and simplify using identities.
  • Example: If \(x = \sec(\theta)\), then \(x^2 - 1 = \sec^2(\theta) - 1 = \tan^2(\theta)\).

4. Practice Problems and Answers

Problem 1

Simplify: \(\cos(x)\sec(x)\)

Solution: \(\sec(x) = \frac{1}{\cos(x)}\), so \[ \cos(x)\sec(x) = \cos(x) \cdot \frac{1}{\cos(x)} = 1 \]

Problem 2

Simplify: \(\frac{1}{1 + \tan^2(x)}\)

Solution: \(1 + \tan^2(x) = \sec^2(x)\) \[ \frac{1}{1 + \tan^2(x)} = \frac{1}{\sec^2(x)} = \cos^2(x) \]

Problem 3

Write in terms of sines and cosines: \(\cot(x)\)

Solution: \[ \cot(x) = \frac{\cos(x)}{\sin(x)} \]

Problem 4

Verify the identity: \(1 + \cot^2(x) = \csc^2(x)\)

Solution: This is a Pythagorean identity.

Problem 5

Make the following substitution and simplify: If \(x = 2\tan(\theta)\), find \(4 + x^2\) in terms of \(\theta\).

Solution: \[ 4 + x^2 = 4 + (2\tan(\theta))^2 = 4 + 4\tan^2(\theta) = 4(1 + \tan^2(\theta)) = 4\sec^2(\theta) \]
