1. The circle with center at (7, -5) passes through the origin. What is the sum of all possible radii that are integers?

Let the center be \( C = (7, -5) \), origin \( O = (0, 0) \). The radius is the distance \( r = |CO| = \sqrt{(7-0)^2 + (-5-0)^2} = \sqrt{49 + 25} = \sqrt{74} \).

But the problem asks for all possible integer radii, suggesting more than one circle is possible: that is, circles with center at \( (7,-5) \) and yet passing through the origin, but with integer radius.

Is it asking for all possible integer radii if we allow circles with integer radii passing through the origin and center at (7, -5)?

But for a circle with center at \( (7,-5) \) to pass through the origin, the radius is forced to be \( r = \sqrt{(7-0)^2 + ((-5) - 0)^2} = \sqrt{74} \).

But if we see "all possible radii that are integers," maybe it's asking for all circles with center at (7, -5), passing through the origin, with integer-valued radius—but since \( \sqrt{74} \) is not an integer, there are no such radii.

But perhaps the words mean: a circle with center at (7, -5) passes through the origin; what are all possible integer values the radius could take—in other words, for all centers at (7, -5), what possible integer values could the distance from (7, -5) to (0, 0) be? But that's just \( \sqrt{74} \).

Alternatively, perhaps the question allows that the circle passes through the origin and has integer radius, in which case the center may vary. But the problem says "circle with center at (7, -5)." Therefore the answer is:

\[ \boxed{0} \]

There are no integer radii for such a circle. Sum is 0.

2. The parabola \( y^2 = 8x \) and the circle \( x^2 + y^2 = 16 \) intersect at points A and B in the first quadrant. Find the exact distance between A and B.

Let’s solve the system for intersection points in the first quadrant.

Let \( y^2 = 8x \) and \( x^2 + y^2 = 16 \).

Substitute \( y^2 = 8x \) into the circle:

\[ x^2 + 8x = 16 \implies x^2 + 8x - 16 = 0 \]

This quadratic in \( x \):

\[ x = \frac{ -8 \pm \sqrt{64 + 64} }{2} = \frac{ -8 \pm \sqrt{128} }{2 } = \frac{ -8 \pm 8\sqrt{2} }{2 }= -4 \pm 4\sqrt{2} \]

Since we want \( x > 0 \), take the "+" sign:

\[ x_1 = -4 + 4\sqrt{2} \]

Now, \( y^2 = 8x = 8(-4 + 4\sqrt{2}) = -32 + 32\sqrt{2} \), so \( y = \sqrt{ -32 + 32\sqrt{2}} \)

For the first quadrant, \( y > 0 \).

Let’s write explicitly:

Let’s check if \( -32 + 32\sqrt{2} > 0 \):

\[ 32(\sqrt{2}-1) > 0 \implies \sqrt{2} \approx 1.414,\ \sqrt{2}-1 \approx 0.414 > 0 \] So positive.

Thus, \[ y_1 = \sqrt{8x_1} = \sqrt{8(-4 + 4\sqrt{2})} = \sqrt{ -32 + 32\sqrt{2}} \]

Similarly, the second solution is for \( x_2 = -4 - 4\sqrt{2} \), which is negative and thus not in first quadrant.

Therefore, both points \( A \) and \( B \) correspond to \( y = \pm \sqrt{ -32 + 32\sqrt{2} } \), i.e., symmetric with respect to the x-axis.

Thus, with coordinates:

\[ A = (x_1, y_1), \quad B = (x_1, -y_1) \]

So the distance between \( A \) and \( B \) is \( 2|y_1| \):

\[ AB = 2\sqrt{ -32 + 32\sqrt{2} } \]

Let's simplify:

\( -32 + 32\sqrt{2} = 32(\sqrt{2} - 1) \)

Thus, \( AB = 2\sqrt{32(\sqrt{2} - 1)} = 2 \times \sqrt{32} \times \sqrt{\sqrt{2} - 1} \)

But \( \sqrt{32} = 4\sqrt{2} \), so \[ AB = 2 \cdot 4\sqrt{2}\cdot \sqrt{ \sqrt{2} - 1} = 8\sqrt{2} \sqrt{\sqrt{2} - 1} \]

Or, set \( s = \sqrt{2} - 1 \), so

\( AB = 8\sqrt{2s} \)

But simplest is: \[ \boxed{8\sqrt{2}\sqrt{\sqrt{2} - 1}} \]

\[ [ -4p m]^2 - 4 \cdot 1 \cdot ( -4 p^2 ) = 0 \] \[ 16p^2 m^2 + 16p^2 = 0 \] \[ m^2 + 1 = 0 \implies m^2 = -1 \implies m = \pm i \]

Based on the given data and standard results, for a parabola \( x^2 = 4 p y \) and line through focus and tangent, the absolute value of the slope is always \( 1 \).

4. A parabola with vertex at the origin opens upward and has a directrix at \( y = -d \). If the area enclosed between the parabola and the x-axis from \( x = -d \) to \( x = d \) is exactly 8, what is \( d \)?

First, standard parabola opening up, vertex at the origin, directrix at \( y = -d \):

The focus is at \( y = d \), so the equation is:

Point \( (x, y) \) satisfies: distance to focus \( (0,d) \) equals distance to directrix \( y = -d \):

\[ \sqrt{ x^2 + (y-d)^2 } = y + d \] \[ x^2 + (y - d)^2 = (y+d)^2 \] \[ x^2 + y^2 - 2 y d + d^2 = y^2 + 2 y d + d^2 \] \[ x^2 - 2y d = 2 y d \implies x^2 = 4 y d \implies y = \frac{ x^2 }{4 d } \]

Find the area between this parabola and the x-axis from \( x = -d \) to \( x = d \):

\[ A = \int_{-d}^d y dx = \int_{-d}^d \frac{x^2}{4d} dx = \frac{1}{4d} \int_{-d}^{d} x^2 dx \] But \( \int_{-d}^{d} x^2 dx = \left[ \frac{1}{3} x^3 \right]_{-d}^d = \frac{1}{3} (d^3 - (-d)^3 ) = \frac{1}{3} (d^3 + d^3) = \frac{2}{3}d^3 \) So \[ A = \frac{1}{4d} \cdot \frac{2}{3} d^3 = \frac{1}{6} d^2 \] Set \( \frac{1}{6} d^2 = 8 \implies d^2 = 48 \implies d = \sqrt{48} = 4\sqrt{3} \)

\[ \boxed{4\sqrt{3}} \]

6. A point P moves in the plane so that its distance from (3, 0) is equal to its distance from the line \( x = -1 \). Find the equation of the locus, and then determine the coordinates where this locus meets the x-axis.

Let \( P = (x, y) \).

Distance to (3, 0):

\[ \sqrt{ (x - 3)^2 + y^2 } \]

Distance to the line \( x = -1 \):

Since \( x = -1 \) is a vertical line, the distance is \( |x + 1| \).

Set equal:

\[ \sqrt{ (x - 3)^2 + y^2 } = |x + 1| \]

Square both sides:

\[ (x - 3)^2 + y^2 = (x + 1)^2 \] \[ x^2 - 6x + 9 + y^2 = x^2 + 2x + 1 \] \[ x^2 - 6x + 9 + y^2 - x^2 - 2x - 1 = 0 \] \[ -8x + 8 + y^2 = 0 \implies y^2 = 8x - 8 \]

So the equation of the locus is:

\[ \boxed{y^2 = 8x - 8} \]

Now, where does this meet the x-axis? That is, for \( y = 0 \):

\[ 0 = 8x - 8 \implies x = 1 \]

So, intersection points with the x-axis are \( (1, 0) \).

\[ \boxed{(1,\, 0)} \]
